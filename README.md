Banking Bureau Analysis | MySQL & Power BI

Project Overview
The Banking Bureau Analysis project focuses on analyzing loan portfolios, borrower characteristics, lending patterns, and credit risk using MySQL and Power BI.
The project uses a structured banking dataset to perform SQL-based data validation and analysis and to develop interactive dashboards that support portfolio monitoring and risk assessment.

Objectives
Validate data quality and identify missing or duplicate records.
Analyze borrower characteristics and demographic distributions.
Examine loan account types and lending patterns.
Analyze contributor and geographic distributions.
Explore loan combinations across borrowers.
Monitor overdue accounts and delinquency risk.
Present key insights through interactive Power BI dashboards.

Tools & Technologies
MySQL Workbench: SQL queries, data validation, joins, aggregations, and analysis.
Microsoft Power BI: Data visualization, KPI cards, charts, and interactive dashboards.
SQL: Filtering, grouping, joins, conditional logic, and data-quality checks.

Power BI Dashboards

1. Executive Overview
Provides a high-level view of key portfolio indicators.

2. Market Share Analysis
Examines the distribution of lending across available contributors.

3. Customer Analysis
Explores borrower demographics, age groups, income levels, and geography.

4. Loan Analysis
Examines loan account types and portfolio distribution.

5. Risk Analysis
Explores overdue balances and delinquency indicators, where supported by the dataset.

This repository is intended to demonstrate analytical methods and dashboard design. Sensitive borrower information, personal identifiers, confidential records, credentials, and unauthorized source data must not be published.
